# Mac runbook

The current ordered commands are in [the short README](../README.md).

Use `bash oct.sh setup`, then `bash oct.sh test`, then `bash oct.sh run "/path/to/OCT2017"`, then `bash oct.sh show`.

For full data, add `--full` to run and show. For detailed options see [USAGE.md](USAGE.md).

The default is now frozen pretrained DINOv2 on PyTorch CPU, not the earlier MLX adaptation experiment.
